## TC-003 — Verify Login with Valid Credentials
- Application: SauceDemo
# Test Type: Functional Testing — Positive Scenario
# Test Status: PASS
# Test Objective
Verify that a user can successfully log in using valid credentials.
## Preconditions
- The SauceDemo website is accessible.
- The user has valid login credentials.
- The login page is displayed.
 # Test Steps
- Open https://www.saucedemo.com/
- Enter a valid username.
- Enter the correct password.
- Click the Login button.
- Verify that the Products page appears.
## Expected Result
The user successfully logs in and is redirected to the Products page.
## Actual Result
The Products page was displayed successfully after login.
## Test Status
PASS
## Conclusion
The login functionality worked as expected during this test execution.
